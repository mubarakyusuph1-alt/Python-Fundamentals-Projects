## Project 1: Fahrenheit to Celsius Temperature Converter

**File:** `IN501_Yusuph_Unit1_Assignment.py`

### Description
Developed a Python program that accepts three user-entered temperatures in Fahrenheit, converts each temperature to Celsius, and calculates the average temperature in both units.

The program displays the temperatures and their averages in a two-column format for easy comparison.

### Skills Demonstrated
- Python variables and data types
- User input and integer conversion
- Mathematical calculations
- Temperature conversion formulas
- Calculating averages
- Formatted output

## Project 2: Project Employee Hours Lookup

**File:** `IN501_Yusuph_Unit2_Assignment.py`

### Description
Developed a Python program that allows users to enter a project number and employee name to retrieve the number of hours recorded for that employee on a specific project.

The program uses conditional logic to validate project numbers and employee names, including differences in capitalization, and displays appropriate messages when a project or employee cannot be found.

### Skills Demonstrated
- Python conditional statements (`if`, `elif`, `else`)
- User input handling
- Dictionary-based data lookup
- String manipulation
- Input validation
- Error handling through conditional checks
